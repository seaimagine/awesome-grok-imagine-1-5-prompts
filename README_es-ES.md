## Plantilla base en español

```text
Genera un vídeo de [10] segundos, [16:9], con estilo [cinematográfico realista / animación 2D / UGC móvil].

SUJETO FIJO: [Rostro, pelo, ropa, colores, geometría del producto y cantidad de objetos que no deben cambiar].
ESCENA: [Lugar], [hora], [luz], [clima y fondo].

CRONOLOGÍA:
0–3 s — [Encuadre inicial y una acción clara].
3–7 s — [Desarrollo con peso, inercia, contacto y reacción de cámara].
7–10 s — [Resultado; mantener el último plano estable durante un segundo].

CÁMARA: [Plano], [movimiento], [sensación de lente], [enfoque].
FÍSICA: [Peso, tela, líquidos, partículas, gravedad y contacto con el suelo].
AUDIO: [Ambiente], [foley]. Diálogo exacto: «[FRASE]», dicho con tono [TONO] y sincronización labial natural.
CONTINUIDAD: Mantener identidad, ropa, número de objetos, proporciones, luz y dirección de movimiento.
EVITAR: caras deformadas, manos o extremidades adicionales, movimiento de goma, objetos flotantes o duplicados, parpadeo, texto ilegible, logos, subtítulos y marcas de agua.
```

Para datos técnicos actualizados, consulta la [documentación oficial de xAI](https://docs.x.ai/developers/model-capabilities/video/generation).
