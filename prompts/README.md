## Placeholder convention

Replace bracketed variables before generating. Keep literal dialogue inside quotation marks. Delete optional blocks you do not need; shorter prompts are usually easier to control than conflicting prompts.

## Recommended workflow

1. Generate a 6–10 second draft at 480p or 720p.
2. Fix one issue per iteration: subject, action, camera, physics, or audio.
3. Use a clean starting image for product geometry or character identity.
4. Generate the final take at the resolution appropriate for delivery.
