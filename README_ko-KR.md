```text
[10]초, [16:9], [사실적인 영화 / 2D 애니메이션 / 모바일 UGC] 스타일의 영상을 생성한다.

주체 고정: [얼굴, 머리, 의상, 색상, 제품 구조, 물체 수를 정확히 설명하고 끝까지 유지].
장면: [장소], [시간], [조명], [날씨와 배경 활동].

타임라인:
0–3초 — [도입 구도와 하나의 명확한 행동].
3–7초 — [무게, 관성, 접촉점과 카메라 반응을 포함한 행동 전개].
7–10초 — [결과. 마지막 프레임은 1초 동안 안정적으로 유지].

카메라: [샷 크기], [움직임], [렌즈 느낌], [초점].
물리: [무게, 천의 지연, 액체 점도, 입자 방향, 발과 지면의 접촉].
오디오: [환경음], [효과음]. 정확한 대사: “［대사］”, [말투], 자연스러운 립싱크.
연속성: 얼굴, 의상, 물체 수, 제품 비율, 빛과 이동 방향을 유지.
제외: 얼굴 변형, 손가락·팔다리 추가, 고무 같은 움직임, 공중 부양, 물체 복제, 깜빡임, 깨진 글자, 로고, 자막, 워터마크.
```
